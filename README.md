# Практика — личный тренер по программированию

Тренажёр для обучения с нуля по 20–30 минут в день: короткая история, одна идея и практика с **настоящим Python прямо в браузере**. Код проверяется автотестами, при ошибке наставник коротко разбирает её: где → почему → попробуй → проверь. Прогресс хранится на устройстве, уроки и Python можно скачать для работы без сети.

Готовность — честно:

- **Учебный цикл для Python работает**: уроки, запуск и проверка кода, разборы ошибок, прогресс и повторения, перенос прогресса файлом, работа без сети в собранной версии.
- **Курс готов частично.** Сейчас готовы модули 0–9 (60 уроков: от первой программы до автоматических тестов). Каждый урок модулей 2–9 прошёл автопроверку в настоящем Python и рецензию: методист, инженер проверок, ученик-новичок. Модули 10–13 ещё пишутся. Карта из 14 модулей, 10 лабораторий-направлений и 4 проектов уже есть. Точный счёт — на экране «Курс».
- **Среды для лабораторий** (веб-страницы, игры, мобильная разработка) ещё не реализованы — такие уроки пока нельзя выполнить в приложении.
- **На реальном Android-устройстве** приложение ещё не проверялось (см. [docs/android.md](docs/android.md)).

## Быстрый запуск на Windows

1. Установи **Node.js** (версия 22.18 или новее, лучше LTS 24) с https://nodejs.org.
2. Дважды щёлкни файл **`Запустить.cmd`** в папке проекта.
   При первом запуске установятся зависимости (нужен интернет, пара минут), затем приложение соберётся и откроется в браузере по адресу http://127.0.0.1:4173.
3. Чтобы остановить — закрой чёрное окно.

То же самое из терминала (PowerShell или cmd, в папке проекта):

```bash
npm install
```

```bash
npm start
```

Сервер открыт только для этого компьютера (`127.0.0.1`), в сеть он не выставляется.

## Работа без сети

1. Открой приложение один раз с интернетом — оболочка сохранится автоматически.
2. **Настройки → Работа без сети**: скачай Python (≈ 13 МБ, один раз для всех модулей) и нужные модули.
3. После этого уроки открываются и проверяются без интернета. Статус «Скачан / Доступен без сети» означает, что файлы действительно лежат в хранилище браузера.

Офлайн-режим работает в собранной версии (`npm start`), а не в режиме разработки (`npm run dev`).

## Телефон (Android)

`localhost` компьютера на телефоне недоступен, а для установки приложения нужен HTTPS. Выбранная схема — бесплатный статический хостинг GitHub Pages с готовым сценарием публикации. Пошагово: [docs/android.md](docs/android.md).

Прогресс между устройствами переносится файлом: **Настройки → Прогресс и резервные копии → Сохранить в файл**, затем «Выбрать файл» на другом устройстве (с выбором «объединить» или «заменить»).

## Рынок труда

В «Направлениях» у каждой лаборатории есть раздел «Работа и заказы». Суммы показываются только из проверенных обзоров. В комплекте есть обзор **«Международный фриланс и удалёнка, USD»**: 51 запись, проверено 26.09.2026, у каждой суммы ссылка, дата и дословная цитата. Загрузить его можно так: **Настройки → Рынок труда → Готовые обзоры → «Загрузить»**. Источники и ограничения описаны в [docs/market-sources.md](docs/market-sources.md). Объявления — это предложения, а не выплаты, и данные устаревают: обзор стоит обновлять.

## Наставник

- **Подсказки курса** (по умолчанию) — заранее написанные подсказки трёх уровней и разборы типичных ошибок. Работают всегда, в том числе без сети. Это не ИИ.
- **ИИ-наставник** — через небольшой сервер-адаптер на твоём компьютере (`npm run coach`). Ключ API хранится только в файле `.env` у адаптера и не попадает в приложение. Для удалённого адаптера (например, с телефона) в настройках приложения хранится токен доступа к адаптеру — это не ключ API, но беречь его всё равно нужно (см. «Ограничения и безопасность»). Запросы платные и отправляются только по кнопке. Настройка: [docs/coach.md](docs/coach.md).

## Команды

| Команда | Что делает |
| --- | --- |
| `npm start` | Собрать и запустить готовую версию (http://127.0.0.1:4173) |
| `npm run dev` | Режим разработки с автообновлением (http://127.0.0.1:5173) |

| `npm run content` | Проверить и собрать учебные материалы из `content/` |
| `npm run verify:content` | Прогнать эталоны, другие верные решения, неверные решения (с ожидаемым разбором) и прогнозы всех уроков в настоящем Python (Pyodide) |
| `python scripts/quick-check.py <урок>` | Быстрая самопроверка урока на обычном Python (`--root <папка>` — материалы, собранные в другой папке) |
| `npm test` | Модульные тесты (vitest) |
| `npm run test:e2e` | Сквозные тесты в Microsoft Edge (Playwright): учебный цикл, офлайн, экспорт/импорт, телефон |
| `npm run screenshots` | Скриншоты всех экранов и состояний (список — `scripts/ui-states.ts`) на ширинах 1440, 1024, 768, 390, 320 в обеих темах: кадр окна и кадр «страницей» (`-full`); предупреждает о горизонтальной прокрутке (нужен запущенный сервер, `--url=…`, `--screens=…`, `--widths=…`, `--themes=…`) |
| `node scripts/ui-audit.ts --url=http://127.0.0.1:5173` | Аудит читаемости тех же состояний: контраст по ролям текста, текст поверх кода и картинок, кегли, межстрочный, капс, наложения и зазоры, обрезка, касаемые области на телефоне, статусы только цветом, поясняющие фразы, кольцо фокуса. Отчёт — `screenshots/audit/report.json` и кадры с рамками вокруг находок |
| `npm run coach` | Сервер-адаптер ИИ-наставника (нужен `.env`, см. docs/coach.md) |

## Как устроено

- **Интерфейс:** React 19 + TypeScript 6 + Vite 8, редактор CodeMirror 6, значки lucide-react. Оформление «Мастерская»: тёплый графит (тёмная тема) и светлая бумага (светлая), один акцент — янтарь. Шрифты IBM Plex Sans (интерфейс и текст урока) и JetBrains Mono (код, адреса `main.py:4`, числа-счётчики) хранятся локально (@fontsource), только кириллица и латиница.
- **Оболочка:** на ПК — полоса разделов слева, вкладки открытых документов сверху, строка состояния снизу (Python, сеть, наставник, проверки урока); на телефоне — верхняя строка и нижняя навигация, урок — со своей шапкой и доком кнопок. Урок — панели «Задание | Редактор и Проверка | Наставник» с конвейером шагов «Понять — Сделать — Закрепить»; на узком экране — вкладки «Задание / Код / Наставник».
- **Стили:** `src/styles/tokens.css` (цвета обеих тем, кегли, отступы; контраст проверяет `tokens.test.ts`), `base.css`, `ui.css` (общие компоненты), `shell.css` (оболочка), `screens/*.css` (по экрану), `learning-visuals.css` (иллюстрации и учебные модели). Правила читаемости: основной текст ≥ 10:1, вторичный ≥ 7:1, текст урока ≥ 16 px, интерфейс ≥ 13 px, код ≥ 14 px, статусы — значок и слово; интерфейс не объясняет сам себя. Проверка — `scripts/ui-audit.ts`.
- **Python:** Pyodide 314 (Python 3.14) в отдельном Web Worker. Ограничение времени (3 с на тест), лимит вывода, кнопка «Остановить»; бесконечный цикл прерывается перезапуском потока. Одновременно выполняется одна программа.
- **Проверка:** `src/runner/harness.py` запускает код ученика, подставляет ввод из тестов и сравнивает настоящий вывод с ожидаемым. Никаких «проверок» регулярными выражениями вместо запуска и подставных ответов. Требования к устройству кода («посчитай из переменных») проверяются по тому, откуда берётся значение, а не по числу строк или имён: верное решение, написанное по-другому, тоже принимается.
- **Материалы:** YAML в `content/` → проверка схемой (`src/content/schema.ts`) → JSON. У урока есть id, цель, история и шаги; набор шагов зависит от урока. Обычный урок с Python — теория, разобранный пример, прогноз, задания с тестами, подсказками трёх уровней, эталоном и типичными неверными решениями, итог. Урок про внешние инструменты (0.4 — редактор, файл, терминал) состоит из чек-листов, которые ученик отмечает сам, без автопроверки. Самостоятельная работа (1.6) идёт без разобранного примера. `npm run verify:content` прогоняет эталоны, другие верные решения и неверные решения (с ожидаемым разбором) в настоящем Python.
- **Окружение запуска:** каждый запуск и каждый тест идёт в новой пустой рабочей папке (в браузере — виртуальная файловая система Pyodide). Задание может дать учебные файлы, базы SQLite, `seed` для `random` и заранее записанные ответы сервера — `requests` в уроках всегда учебная симуляция, настоящих сетевых запросов нет. Файлы, которые создала программа, видны под выводом («Файлы после запуска»).
- **Справочник для авторов уроков:** [docs/content-format.md](docs/content-format.md) — все поля урока, шагов, заданий и тестов, правила, разборы ошибок, файлы, базы, `seed`, сеть и как проверить урок. Примеры в нём взяты из урока-образца `scripts/fixtures/engine`, который проверяется настоящим Python.
- **Данные:** IndexedDB, версия схемы, экспорт/импорт JSON с автоматической резервной копией перед заменой. Повреждённый файл не меняет данные.
- **Офлайн:** собственный service worker с явным списком файлов, отдельные кеши для оболочки, Python и уроков, обновление по кнопке «Обновить».

```
content/          учебные материалы (YAML): course.yaml и lessons/
src/runner/       Python-обвязка, Web Worker, управление запуском
src/app/          оболочка «Мастерская»: каркас, вкладки документов, строка состояния, маршруты
src/components/   общие компоненты: кнопки, метки, статусы, код, конвейер шагов, маршрут
src/styles/       токены, основа, общие компоненты, оболочка и стили экранов
src/screens/      экраны: Сегодня, Курс, Урок, Направления, Проекты, Прогресс, Настройки
src/storage/      IndexedDB, экспорт/импорт, расписание повторений
src/coach/        разбор ошибок и подсказки курса, клиент ИИ-наставника
server/           адаптер ИИ-наставника (Node, только 127.0.0.1)
coach/            системный промпт наставника
build/            плагины сборки: материалы, Pyodide, service worker
scripts/          проверки материалов, скриншоты и аудит читаемости (ui-states, screenshots, ui-audit), иконки
e2e/              сквозные тесты
```

## Ограничения и безопасность

- Web Worker защищает интерфейс от зависаний, но **не является песочницей безопасности**. Ключа API в приложении нет, код ученика выполняется только у него в браузере. Но поток с Python открыт с того же адреса, что и приложение, а в хранилище приложения (IndexedDB) лежат прогресс, настройки и — если настроен удалённый наставник — его токен доступа. Поэтому до первого запуска кода ученика поток лишается доступа к IndexedDB, Cache Storage, сети и запуску новых потоков. Это снижает риск, но не заменяет полной изоляции (запуска кода на отдельном адресе) — её пока нет. Не запускай в тренажёре чужой код, которому не доверяешь, а токен удалённого наставника, если он мог утечь, замени на сервере (см. docs/coach.md).
- `input()` работает с заранее заданным вводом (тесты и поле «Ввод»), а не интерактивно.
- Сеть в уроках — учебная симуляция: `requests` отвечает только заранее записанными ответами задания, настоящих запросов нет. Учебные файлы живут только в рабочей папке запуска и удаляются после него.
- Скрытые тесты доставляются в браузер, поэтому тренажёр не подходит для экзаменов. Для личного обучения это нормально.
- Очистка данных браузера удаляет локальный прогресс — время от времени сохраняй резервную копию (Настройки).
- Работа на реальном Android-устройстве ещё не проверялась, см. docs/android.md.
- Уроки с HTML/CSS/JS, играми и мобильной разработкой (лаборатории) требуют отдельных сред и пока не готовы.
- Новая версия приложения применяется по кнопке «Обновить». Скачанные для офлайна модули, которые изменились в новой версии, service worker при обновлении скачивает заново сам (если есть сеть); если сети не было, статус в «Настройках → Работа без сети» покажет, что модуль нужно скачать снова.
