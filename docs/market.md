# Обзоры рынка труда: формат и правила

В разделе «Работа и заказы» (экран «Направления») суммы появляются **только** из проверенного обзора, который импортируется в «Настройки → Рынок труда → Импортировать обзор». Пока обзора нет, приложение честно пишет «Данные ещё не загружены». Само подключение ИИ не даёт доступа к вакансиям — обзор готовится отдельно: вручную или через поиск с проверкой источников.

## Правила

- Зарплата в найме (`salary`), ставка фрилансера за час (`hourly`) и бюджет заказа (`project`) — разные записи. Их нельзя смешивать и пересчитывать друг в друга (например, умножать ставку на 160 часов).
- У каждой записи обязательны: регион, валюта, уровень специалиста, период, дата проверки и прямая ссылка. Без ссылки или даты запись не принимается. Даты пишутся как `ГГГГ-ММ-ДД`: несуществующая дата, дата из будущего или текст вместо даты («не помню когда») не принимаются.
- Объявление (вакансия, заказ, ставка в профиле) — это **предложение**, а не выплата: `isOffer: true`. Несколько объявлений — не «средняя цена рынка».
- Суммы указываются до налогов и комиссий, если в источнике не сказано иначе.
- Желательно два независимых источника. Если источник один или выборка маленькая — напиши это в `note`.
- Приложение помечает данные старше 30 дней как «могли устареть».

## Формат файла

```json
{
  "format": "praktika-market",
  "title": "Обзор: автоматизация, фриланс",
  "region": "Международный фриланс",
  "currency": "USD",
  "checkedAt": "2026-09-26",
  "entries": [
    {
      "lab": "automation",
      "type": "project",
      "title": "Скрипт обработки CSV-отчётов (объявление)",
      "amountMin": 100,
      "amountMax": 250,
      "currency": "USD",
      "period": "project",
      "region": "Международный фриланс",
      "level": "начальный",
      "publishedAt": "2026-09-20",
      "checkedAt": "2026-09-26",
      "url": "https://example.com/ссылка-на-конкретное-объявление",
      "sourceType": "order",
      "isOffer": true,
      "note": "Одно объявление, бюджет предложен заказчиком — не фактическая оплата."
    }
  ]
}
```

Цифры и ссылка в примере — **условные, для показа формата**. Импортировать их как настоящие нельзя.

Поля записи:

| Поле | Значения |
| --- | --- |
| `lab` | id направления: `web`, `backend`, `automation`, `data`, `ai`, `mobile`, `games`, `qa`, `security`, `systems` |
| `type` | `salary` — зарплата в найме, `hourly` — ставка за час, `project` — бюджет заказа |
| `amountMin`, `amountMax` | числа или `null` (хотя бы одно должно быть задано) |
| `currency` | трёхбуквенный код: `RUB`, `USD`, `EUR`, `KZT`… |
| `period` | `month`, `year`, `hour`, `project` |
| `level` | уровень специалиста так, как указан в источнике |
| `publishedAt` | дата публикации в виде `ГГГГ-ММ-ДД` (или `null`, если её нет); не позже `checkedAt` |
| `checkedAt` | дата, когда источник проверен, в виде `ГГГГ-ММ-ДД`; не из будущего (так же и `checkedAt` всего обзора) |
| `sourceType` | `vacancy`, `order`, `statistics`, `survey`, `platform` |
| `isOffer` | `true` — объявление или предложение, `false` — подтверждённая оплата или статистика выплат |
