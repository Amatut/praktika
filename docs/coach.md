# Личный тренер с ИИ

В «Практике» два режима помощи:

- **«Подсказки курса»** — работают сразу и без интернета: заранее написанные подсказки и разборы типичных ошибок. Ничего настраивать не нужно.
- **«ИИ»** — наставник отвечает на твои вопросы по текущему заданию. Для этого на компьютере запускается маленький сервер — **адаптер наставника** (`server/coach-server.ts`). Приложение обращается только к нему, а он — к ИИ-провайдеру (Anthropic, через официальный SDK). Ключ API хранится только у адаптера, в файле `.env`, и никогда не попадает в приложение, браузер или репозиторий.

Запросы к ИИ отправляются только когда ты сам нажимаешь кнопку. Без адаптера и ключа всё обучение работает как обычно.

## Сколько это стоит

**Запросы к ИИ платные.** Anthropic берёт плату за токены (кусочки текста): отдельно за то, что уходит модели (условие, твой код, результаты тестов, инструкции наставника), и за ответ. Поэтому цена каждого запроса зависит от длины — фиксированной цены нет.

Расчёт: `цена ≈ входные токены × цена входа + выходные токены × цена выхода`.

Цены по данным на июнь 2026 года (за 1 миллион токенов, вход / выход) — перед началом проверь актуальные на странице https://platform.claude.com/docs/en/about-claude/pricing:

| Модель (`COACH_MODEL`) | Вход | Выход |
| --- | --- | --- |
| `claude-opus-5` (по умолчанию) | $5 | $25 |
| `claude-sonnet-5` | $2 | $10 |
| `claude-haiku-4-5` | $1 | $5 |

Расчёт для `claude-opus-5` — это оценка, а не обещание: сколько токенов займёт текст, заранее точно не знает никто.

**Обычный запрос (ориентир).** Инструкции наставника — около 2–3 тысяч токенов, условие, твой код и сводка тестов — ещё 1–3 тысячи, ответ вместе с рассуждениями модели — обычно 150–400 токенов. Получается порядка **$0,02–0,04 за запрос**. Короткий вопрос без кода — дешевле, «Подробнее» — дороже.

**Потолок одного запроса.** Адаптер ограничивает:

- запрос — 24 КБ. Русский текст занимает 2 байта на букву, и 24 КБ — это несколько тысяч токенов. Но код из латиницы и знаков может дать почти токен на символ: до ~24 тысяч токенов плюс инструкции — около 27 тысяч, то есть **до ≈ $0,135** за вход;
- ответ — 600 токенов (`COACH_MAX_TOKENS`), для «Подробнее» — вдвое больше, 1200. В этот предел входят и рассуждения модели. Это **до ≈ $0,015** (для «Подробнее» — до ≈ $0,03).

Итого реальный потолок — **около $0,15–0,17 за запрос** и **около $17 в сутки** при лимите 100 запросов (`COACH_DAILY_LIMIT`). Лимиты можно уменьшить в `.env` — потолок уменьшится пропорционально.

Что ещё влияет на цену:

- **Кеш инструкций.** Инструкции наставника одинаковы в каждом запросе, поэтому адаптер просит их кешировать. Первый запрос (и первый после перерыва больше 5 минут) платит за них в 1,25 раза дороже обычного, следующие в течение 5 минут — примерно десятую часть. На `claude-opus-5` и `claude-sonnet-5` кеш срабатывает. На `claude-haiku-4-5` — нет: у неё кешируется только текст от 4096 токенов, а инструкции короче, поэтому за них всегда платится полная (впрочем, низкая) цена.
- **Резервная модель.** Изредка фильтр безопасности модели по ошибке отклоняет безобидный учебный вопрос. Тогда API сам повторяет запрос на резервной модели (бета-функция Anthropic `server-side-fallback-2026-07-01`, режим `fallbacks: "default"`; включается для `claude-opus-5` и `claude-fable-5-1`). Если отказ случился до начала ответа, он бесплатный; если после — оплачивается и начало ответа, и повтор. Такой запрос может стоить до двух раз дороже, но это редкость. Если API отвечает на запрос с резервной моделью ошибкой 400 (например, твоей организации эта бета-функция недоступна), адаптер один раз повторяет запрос без неё — отклонённый запрос не оплачивается. Если без неё запрос прошёл, резервная модель выключается до перезапуска адаптера.

Число токенов адаптер пишет в своё окно после каждого ответа и отдаёт приложению (поле `usage`); при повторе на резервной модели там видна только последняя попытка. Фактические расходы смотри в Claude Console.

### Почему по умолчанию `claude-opus-5`

Ответ наставника короткий, но требовательный: нужно точно найти главную причину ошибки по реальным результатам тестов, не выдумывать запуски, не выдавать решение раньше времени и держать уровень подсказки. Более сильная модель надёжнее соблюдает эти правила. Цена при этом ограничена сверху: адаптер просит у модели неглубокие рассуждения (`COACH_EFFORT=low`), ограничивает длину ответа (600 токенов, для «Подробнее» — 1200) и размер запроса (24 КБ).

Если хочется дешевле — это твоё решение, достаточно одной строки в `.env`: `COACH_MODEL=claude-sonnet-5` (по ценам примерно в 2,5 раза дешевле) или `COACH_MODEL=claude-haiku-4-5` (по ценам в 5 раз дешевле, но без кеша инструкций — см. выше; объяснения может давать проще и чуть менее точно).

## Настройка на Windows

Нужны Node.js 24 и установленный проект (`npm install`), как для запуска самого приложения.

### 1. Получи ключ API

1. Открой Claude Console: https://platform.claude.com и войди (или зарегистрируйся).
2. В разделе оплаты (Billing) добавь способ оплаты или пополни баланс — без этого запросы не пройдут.
3. В разделе **API Keys** нажми «Create Key» и скопируй ключ. Он показывается один раз.
4. Если в консоли можно задать лимит расходов, поставь небольшой — это дополнительная защита.

Ключ — как пароль: не отправляй его в чаты, не вставляй в приложение и не коммить в git.

### 2. Создай файл `.env`

В PowerShell в папке проекта:

```powershell
Copy-Item .env.example .env
notepad .env
```

Впиши ключ после знака `=` без кавычек и пробелов и сохрани файл:

```
ANTHROPIC_API_KEY=sk-ant-...твой ключ...
```

Остальные строки можно оставить пустыми — тогда работают значения по умолчанию. Файл `.env` уже указан в `.gitignore` и в репозиторий не попадёт.

### 3. Запусти адаптер

```powershell
npm run coach
```

Увидишь примерно такое:

```
Адаптер наставника запущен: http://127.0.0.1:8787
Провайдер: anthropic, модель: claude-opus-5
Ключ API найден. Запросы к ИИ платные: цена зависит от длины запроса и ответа.
Режим: локальный — адаптер доступен только с этого компьютера.
```

Не закрывай это окно, пока занимаешься. Остановить — `Ctrl+C`. Проверить, что адаптер жив, можно в браузере: http://127.0.0.1:8787/health (ответ `"configured": true` значит, что ключ найден). Это единственный адрес, который в локальном режиме отвечает не только приложению: он бесплатный, к ИИ не обращается и ничего секретного не показывает. Запросы к наставнику принимаются только из приложения.

В это же окно адаптер пишет короткий журнал: какие запросы пришли, сколько токенов потрачено и почему запрос отклонён (например, «адрес приложения не разрешён»). Твой код, вопросы и ключ туда не попадают.

Приложение запускай как обычно в другом окне (`npm run dev` или `npm start`).

### 4. Включи ИИ в приложении

В «Настройках» приложения, в разделе соединения с наставником:

1. выбери режим **«ИИ»**;
2. адрес адаптера: `http://127.0.0.1:8787`;
3. токен доступа оставь пустым (он нужен только для удалённого адаптера);
4. проверь соединение.

Если что-то не так, приложение покажет понятное состояние: адаптер не запущен, ИИ не настроен, лимит и т. п. Подсказки курса продолжают работать в любом случае.

### Проверка без оплаты

Чтобы проверить связь приложения с адаптером, не тратя деньги, запусти адаптер в тестовом режиме: в `.env` поставь `COACH_PROVIDER=mock`. Ответы будут помечены «[тестовый режим — это не ИИ]». Не забудь вернуть пустое значение (или `anthropic`), когда закончишь.

## Если что-то не работает

| Что видишь | Что сделать |
| --- | --- |
| «Сервер наставника не запущен или недоступен» | Запусти `npm run coach` и проверь адрес в настройках. Если адаптер уже запущен, посмотри в его окно: строка «доступ запрещён (origin), Origin: …» значит, что приложение открыто с адреса, которого нет в списке (например, другой порт или адрес в сети). Добавь этот адрес в `COACH_ALLOWED_ORIGINS` в `.env` и перезапусти адаптер. |
| «Наставник не ответил за … секунд» или «ИИ не ответил вовремя» | ИИ отвечал слишком долго. Попробуй ещё раз чуть позже. Адаптер ждёт ИИ до 30 секунд (`COACH_TIMEOUT_MS`), приложение — на 5 секунд дольше. |
| «ИИ не настроен» | В `.env` нет ключа `ANTHROPIC_API_KEY`. Впиши ключ и перезапусти адаптер. |
| «Ключ … не принят (ошибка 401)» | Ключ скопирован неполностью или отозван. Создай новый в Claude Console. |
| «Проблема с оплатой» | Пополни баланс в Claude Console. |
| «ИИ-провайдер отклонил запрос (ошибка 400)» | Посмотри в окно адаптера: там статус, тип ошибки, её текст и `request_id` от Anthropic. Например, модель из `COACH_MODEL` может не поддерживать какой-то параметр запроса — тогда верни модель по умолчанию. |
| «ИИ отказался отвечать на этот запрос» | Фильтр безопасности модели счёл запрос опасным, и резервная модель тоже отказала. Переформулируй вопрос; подсказки курса работают. |
| «Лимит: не больше … запросов» | Подожди указанное время или измени `COACH_RATE_LIMIT` / `COACH_DAILY_LIMIT`. |
| «Порт 8787 уже занят» | Адаптер уже запущен в другом окне. Или выбери другой порт (`COACH_PORT`) и поменяй адрес в приложении. |

## Что адаптер делает для безопасности

- Слушает только `127.0.0.1` — с других устройств до него не достучаться.
- Принимает запросы к ИИ только из приложения (проверка заголовка `Origin`) и только на один адрес `POST /coach`; это не открытый прокси к ИИ. Исключение — бесплатная проверка `GET /health`: в локальном режиме она отвечает и без `Origin`, чтобы её можно было открыть в браузере.
- Отправляет модели только нужный контекст: цель урока, условие, твой код, краткую сводку реальных результатов тестов, число открытых подсказок, краткую карточку навыков, твой вопрос (если ты его задал) и несколько последних реплик разговора с наставником. Результаты тестов — это результаты последней проверки: если после неё ты менял код, нажми «Проверить» ещё раз, чтобы наставник разбирал результаты текущей версии. Код и вывод программы передаются как данные: наставник не меняет свою роль, даже если в коде написано иное.
- Ограничивает размер запроса (24 КБ), длину ответа, частоту запросов и время ожидания.
- Обращается к ИИ через официальный SDK Anthropic (`@anthropic-ai/sdk`). SDK работает только в адаптере, в приложение он не попадает. Ключ берётся только из `ANTHROPIC_API_KEY`. Адрес API зафиксирован (`https://api.anthropic.com`): переменные `ANTHROPIC_BASE_URL` и `ANTHROPIC_AUTH_TOKEN`, если они есть в окружении, адаптер не использует. Автоматических повторов нет: каждый повтор мог бы быть оплачен. Исключение — один бесплатный повтор без резервной модели (см. «Сколько это стоит»). Собственный журнал SDK выключен, чтобы в него не попали твой код и вопросы. Ответа ИИ адаптер ждёт не дольше `COACH_TIMEOUT_MS`.
- В журнал пишет только действие, статус, время и число токенов, а при отказе в доступе — ещё адрес приложения (`Origin`). Твой код, вопросы и ключи туда не попадают.

## Телефон и удалённый адаптер

С телефона локальный адаптер **недоступен**: адрес `127.0.0.1` на телефоне означает сам телефон, а не компьютер. Кроме того, приложение, открытое по HTTPS, не может обращаться к адресу по HTTP в домашней сети — браузер это блокирует. Пока удалённый адаптер не настроен, на телефоне работают «Подсказки курса».

Чтобы пользоваться ИИ с телефона, нужен **удалённый адаптер** с HTTPS-адресом. Схема (сейчас ничего из этого не развёрнуто):

1. **Сервер** с постоянным HTTPS-адресом — например, недорогой VPS или всегда включённый компьютер с доменом. На нём Node.js 24 и копия проекта.
2. **Адаптер на сервере** слушает только `127.0.0.1`, а в `.env` на сервере:
   ```
   ANTHROPIC_API_KEY=...ключ...
   COACH_ACCESS_TOKEN=...длинный случайный токен...
   COACH_ALLOWED_ORIGINS=https://адрес-твоего-приложения
   COACH_RATE_LIMIT=10
   COACH_DAILY_LIMIT=50
   ```
   Токен можно сгенерировать так:
   ```powershell
   node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
   ```
   Когда задан токен, адаптер работает в удалённом режиме: без верного токена он отказывает на каждый запрос — ошибкой 401, если адрес приложения разрешён, и 403, если `Origin` чужой или его нет. С верным токеном запрос принимается. Токен сравнивается безопасным способом.
3. **HTTPS-прокси** на том же сервере (например, Caddy или nginx) принимает `https://coach.твой-домен` и передаёт запросы на `http://127.0.0.1:8787`. Порт 8787 наружу не открывается.
4. **В приложении на телефоне**: адрес `https://coach.твой-домен` и тот же токен доступа. Токен хранится только в настройках приложения на устройстве (IndexedDB браузера); это не ключ API. Он доступен любому коду, который выполняется на адресе приложения. Код ученика в тренажёре выполняется в отдельном потоке, у которого до первого запуска отнимается доступ к IndexedDB, Cache Storage и сети, но это не полная изоляция. Поэтому не запускай в тренажёре чужой код, которому не доверяешь. Если токен мог утечь — задай новый `COACH_ACCESS_TOKEN` на сервере и перезапусти адаптер.
5. **Лимиты** (`COACH_RATE_LIMIT`, `COACH_DAILY_LIMIT`) и лимит расходов в Claude Console ограничивают траты, даже если кто-то узнает токен.

Можно запустить адаптер и прямо на сетевом адресе (`COACH_HOST=0.0.0.0` — тогда без токена он не запустится), но для телефона всё равно нужен HTTPS, поэтому вариант с прокси проще и надёжнее.

## Все переменные

| Переменная | По умолчанию | Что это |
| --- | --- | --- |
| `COACH_PROVIDER` | `anthropic` | `anthropic` — настоящий ИИ, `mock` — тестовый режим без ИИ |
| `ANTHROPIC_API_KEY` | — | ключ API, только в `.env` |
| `COACH_MODEL` | `claude-opus-5` | модель |
| `COACH_EFFORT` | `low` | глубина рассуждений: `low`, `medium`, `high` (выше — дороже) |
| `COACH_HOST` | `127.0.0.1` | адрес; не loopback — только с токеном |
| `COACH_PORT` | `8787` | порт |
| `COACH_ACCESS_TOKEN` | — | токен доступа к адаптеру (Bearer), не короче 32 символов |
| `COACH_ALLOWED_ORIGINS` | `http://localhost:5173,http://127.0.0.1:5173,http://localhost:4173,http://127.0.0.1:4173` | адреса приложения |
| `COACH_RATE_LIMIT` | `20` | запросов к ИИ за 10 минут |
| `COACH_DAILY_LIMIT` | `100` | запросов к ИИ за 24 часа |
| `COACH_MAX_TOKENS` | `600` | предел длины ответа в токенах, включая рассуждения модели (64–8192); для «Подробнее» — вдвое больше, но не больше 8192 |
| `COACH_TIMEOUT_MS` | `30000` | сколько адаптер ждёт ответа ИИ, мс (1000–30000); приложение ждёт на 5 секунд дольше |

Инструкции наставника лежат в `coach/system-prompt.md`: там описано, как он отвечает (коротко: где → почему → попробуй → проверь), когда даёт полное решение и чего никогда не делает.
